# 아이템 시스템 기획

> 상태: 기획안 (미구현). 구현 전 합의용 문서.
> 관련: [DESIGN.md](../DESIGN.md), [ROADMAP.md](../ROADMAP.md)

## 0. 결론 먼저

아이템을 **세 축**으로 나눈다.

| 축 | 무엇을 바꾸나 | 누구에게 도움 |
|---|---|---|
| **치장** | 캐릭터 외형 | 재미 |
| **장비** | 게임 내 수치 (EXP·골드) | 캐릭터 |
| **도구** | **앱이 나를 대하는 방식** | **컴퓨터 밖의 사람** |

"치장 + 진짜 오르는 아이템"이라는 두 축은 그대로 두고, **도구**를 세 번째 축으로 추가한다.
이게 "뽑았을 때 실제로 도움이 되는 아이템"에 대한 답이다.

그리고 골드를 태우는 곳은 **여러 개**를 둔다 ([8-1](#8-1-골드를-태우는-곳-sink)).
고정가 상점만 두면 살 걸 다 산 순간 골드가 고인다.

## 1. 핵심 아이디어 — 도구 = AI 프롬프트 모디파이어

이 앱에는 이미 **할 일을 퀘스트로 바꿔주는 AI**가 있다.
아이템이 그 AI의 행동을 바꾸면, 아이템은 게임 안의 숫자가 아니라 **실제로 쓸모 있는 기능**이 된다.

구현도 싸다. 아이템 효과는 결국 `QUEST_SYSTEM_PROMPT`에 덧붙는 한 문장이다.

```
장착: 첫걸음의 신발
→ 프롬프트에 추가: "각 퀘스트에 '처음 5분에 할 일'을 한 줄 덧붙이세요."
```

### 도구 아이템 후보

| 아이템 | 효과 | 현실에서 왜 도움되나 |
|---|---|---|
| **첫걸음의 신발** | 퀘스트마다 "처음 5분에 할 일" 추가 | 미루기의 90%는 시작이 막막해서다 |
| **시간의 모래시계** | 퀘스트마다 예상 소요 시간 표시 | 하루에 뭘 얼마나 넣을 수 있는지 감이 생긴다 |
| **현자의 돋보기** | 큰 퀘스트를 자동으로 3개로 쪼갬 | "보고서 쓰기" 같은 덩어리에 압도되지 않는다 |
| **균형의 저울** | 최근 7일간 비어 있는 능력치를 AI가 챙겨줌 | 운동만 하고 잠은 안 자는 편식을 막는다 |
| **회고의 수정구** | 주 1회, 지난 주 요약 리포트 | 뭘 했는지 보이면 다음 주 계획이 현실적이 된다 |
| **나비의 깃털** | flavor_text 톤 변경 (다정 / 스파르타 / 시크) | 동기부여 방식은 사람마다 다르다 |
| **작심삼일의 부적** | 3일 연속 실패한 분야는 난이도를 낮춰 다시 제안 | 실패한 목표를 조용히 재조정해준다 |
| **쉬어가기 부적** | 하루 놓쳐도 연속 기록 유지 (1회 소모) | 루틴 앱 최대 이탈 지점이 "하루 놓쳐서 포기"다 |
| **집중의 모래주머니** | 퀘스트 1개만 남기고 나머지를 접음 | 한 번에 하나. 멀티태스킹 착각을 끊는다 |

**쉬어가기 부적만 소모품**이고 나머지는 영구다. 소모품이 많으면 아끼느라 안 쓴다.

## 2. 공용 vs 직업 전용 — 방향을 살짝 틀자

공용/전용으로 나누는 것에는 **동의**한다. 다만 전용 아이템의 성격을 바꾸고 싶다.

### 문제

직업 전용이 `STR +10` 같은 **수치 보너스**면 마태 효과가 생긴다.
STR로 전직한 사람이 STR을 더 잘 얻고, 그래서 운동만 하고, 공부와 잠은 계속 비어간다.
**루틴 앱에서 한 분야만 파는 건 좋은 결과가 아니다.**

### 제안

> **직업 전용은 "깊이"를, 공용은 "균형"을 준다.**

전용 아이템은 능력치를 올리지 않는다. 대신 **그 분야를 더 잘하게 돕는 도구**다.

| 직업 | 전용 도구 | 효과 |
|---|---|---|
| 전사 (운동) | **훈련 일지** | 운동 퀘스트에 세트·횟수·휴식 시간을 구체적으로 명시 |
| 현자 (공부) | **집중의 회중시계** | 공부 퀘스트를 25분 단위로 쪼갬 (뽀모도로) |
| 음유시인 (사교) | **대화의 실마리** | 사교 퀘스트에 꺼낼 만한 화제를 함께 제안 |
| 수도사 (건강) | **몸의 소리** | 건강 퀘스트에 수면·수분 체크를 곁들임 |
| 방랑자 (취미) | **우연의 주사위** | 취미 퀘스트를 랜덤으로 하나만 제안 (선택 피로 감소) |

이러면 전용 아이템이 **그 직업을 고른 이유를 보상**하면서도, 다른 분야를 굶기지 않는다.
균형은 공용 도구(`균형의 저울`)가 따로 챙긴다.

## 2-1. 공용 / 직업 전용을 섞는 비율

세 축 **모두** 공용과 직업 전용을 섞는다. 치장도 예외가 아니다.

| 축 | 공용 | 직업 전용 |
|---|---|---|
| 치장 | 60% | 40% |
| 장비 | 60% | 40% |
| 도구 | 대부분 | 직업당 1개 ([2번](#2-공용-vs-직업-전용--방향을-살짝-틀자)) |

### 직업별 치장 테마

| 직업 | 머리 | 등 |
|---|---|---|
| 전사 | 뿔투구 | 붉은 전투 망토 |
| 현자 | 별무늬 고깔 | 별의 로브 |
| 음유시인 | 깃털 모자 | 악보 망토 |
| 수도사 | 수도 두건 | 성포 |
| 방랑자 | 삼각 두건 | 여행 배낭 |

## 2-2. ⚠ 못 쓰는 아이템이 나오면 안 된다

**전사인데 현자 전용이 뽑히면 그건 꽝이다.** 꽝 없는 뽑기를 만들어놓고
직업 잠금으로 다시 꽝을 만들면 아무 의미가 없다.

### 규칙 — 풀 자체를 거른다

> **획득 풀 = 공용 + 내 직업 전용.** 다른 직업 전용은 **애초에 나오지 않는다.**

뽑기·퀘스트 드랍·상점 진열 **전부**에 같은 필터를 건다.
"나왔지만 못 쓴다"가 아니라 "나올 수 없다"로 처리하는 게 핵심이다.

```
견습생 (직업 없음) → 공용만
전사              → 공용 + 전사 전용
```

견습생은 공용만 나온다. 이게 **직업을 정할 이유**를 하나 더 만든다.

### 전직하면 이전 직업 아이템은 잠긴다

사라지지는 않는다. 보관함에 **잠김 표시**로 남고, 다시 그 직업으로 돌아가면 부활한다.

이건 부작용이 아니라 **의도된 전직 억제력**이다.
전사로 모은 전용 장비 일습이 통째로 잠긴다는 사실이,
5,000 G보다 더 강하게 전직을 망설이게 만든다.

전직 확인 패널(`⚠ 운명의 선택 ⚠`)에 이 경고를 추가한다.

```
전사 전용 아이템 4개가 잠깁니다.
(전사로 돌아오면 다시 사용할 수 있습니다)
```

## 3. 세 축 상세

### 치장 (Cosmetic)
- 스프라이트 레이어를 하나 더 얹는다. `lib/sprite.ts`가 이미 레이어 구조라 확장이 싸다
- 슬롯: **머리 / 등 / 손** (모자, 망토, 소품)
- **공용 60% / 직업 전용 40%** ([2-1](#2-1-공용--직업-전용을-섞는-비율))
- 능력치 0. 순수하게 보여주기용
- 획득: 상점 구매, 스트릭 보상
- 예: 밀짚모자, 여행자의 망토, 고양이 귀, 반짝이는 왕관

### 장비 (Equipment)
- 게임 내 수치만 건드린다. **현실 행동엔 영향 없음**
- 효과 종류는 셋으로 제한 — 늘리면 밸런스가 무너진다
  - `EXP +N%`
  - `골드 +N%`
  - `특정 카테고리 EXP +N%`
- 슬롯: **무기 / 방어구 / 장신구**
- 획득: 퀘스트 드랍
- **강화 가능** (`+0` ~ `+10`). 상세는 [8-3](#8-3-장비-강화)

### 도구 (Tool)
- 위 1번 표
- 슬롯: **도구 2칸** (한 번에 2개까지만 — 전부 켜면 AI 응답이 산만해진다)
- 획득: 상점 구매가 기본. 일부는 스트릭·업적 보상으로만

## 4. 게이트 — 레벨 제한만으로는 부족하다

레벨 제한만 걸면 **시간만 지나면 다 얻는다.** 조건에 의미가 없다.
네 가지를 조합한다.

| 게이트 | 의미 | 예 |
|---|---|---|
| **레벨** | 전체 총량 | LV.10 이상 |
| **직업** | 정체성 | 전사만 |
| **능력치** | 그 분야의 깊이 | STR 500 이상 |
| **연속 기록** | **꾸준함** | 7일 연속 달성 |

**연속 기록 게이트가 이 앱에서 가장 고유한 조건이다.**
레벨·능력치·골드는 결국 시간을 갈아 넣으면 얻지만, 연속 기록은 **하루도 빠지지 않아야** 얻는다.
루틴 앱의 최고 등급 보상은 여기에 걸어야 한다.

> 예: **꾸준함의 증표** (30일 연속) — 모든 퀘스트 골드 +20%, 전용 치장 이펙트

---

## 5. 등급 — 퀘스트 랭크를 그대로 쓴다

퀘스트에 이미 `F ~ S` 랭크가 있다. **아이템도 같은 스케일**을 쓴다.
새 등급 체계를 만들면 사용자가 두 벌을 외워야 한다.

| 랭크 | 드랍 확률대 | 성격 |
|---|---|---|
| F·D | 흔함 | 소소한 장비, 기본 치장 |
| C·B | 보통 | 쓸 만한 장비 |
| A | 드묾 | 도구 |
| S | 매우 드묾 | 직업 전용 도구, 연속 기록 보상 |

**높은 랭크 퀘스트일수록 좋은 아이템이 나온다** → 어려운 일을 미루지 않을 이유가 생긴다.

랭크별 테두리는 이미 DESIGN.md에 정의돼 있다 (F·D 2px / C·B 3px / A primary / S primary 채움 + 깜빡임).
아이템 카드에 그대로 재사용한다.

## 6. 획득 경로

1. **퀘스트 완료 드랍** — 퀘스트 랭크 + 카테고리 → 드랍 테이블
2. **상점 구매** — 골드. 도구가 주력 상품
3. **연속 기록 보상** — 7일 / 30일 / 100일.
   여기서만 나오는 아이템은 `streakOnly`로 표시해 **뽑기·드랍·조합·상점 어디에도
   나오지 않게** 막는다. 시간으로 살 수 없는 조건이라는 성격이 무너지면 안 된다
4. **레벨업 보상** — 5레벨마다

### ⚠ 지금 구조에서 반드시 고칠 것

AI가 `rewards.loot`으로 **자유롭게 아이템 이름을 짓고 있다.** 이대로면 시스템으로 관리가 불가능하다
("단단한 허벅지 근육"에 무슨 효과를 붙일 것인가).

> **분리한다.**
> - AI가 짓는 `loot` 이름 → **수집용 기념품**으로 남긴다 (지금의 소지품 패널 그대로. 효과 없음)
> - 실제 효과 아이템 → **코드가 정의한 테이블에서 드랍**한다 (결정론적, 밸런스 조절 가능)

두 층으로 나누면 AI의 작명 재미도 살리고 시스템도 안정된다.

## 7. 슬롯 구성

```
치장:  머리 / 등 / 손        (외형만)
장비:  무기 / 방어구 / 장신구  (수치만)
도구:  2칸                    (AI 동작)
```

치장과 장비를 분리해야 **"좋은 장비인데 못생겨서 안 낌"** 문제가 안 생긴다.
장비는 외형에 영향을 주지 않고, 보이는 건 치장 슬롯이 결정한다.

## 8. 밸런스 기준선

현재 경제: 퀘스트당 골드 5~70. 하루 4개면 **약 100 G**. 전직 비용 **5,000 G**.

| 항목 | 가격대 | 근거 |
|---|---|---|
| 기본 치장 | 100 ~ 300 G | 2~3일치 |
| 도구 | 500 ~ 1,500 G | 일주일 ~ 보름치. 신중히 고르게 |
| 고급 치장 | 2,000 G | 사치품 |
| 전직 | **5,000 G** | 최상단 유지 |

**전직보다 비싼 아이템은 만들지 않는다.** 전직의 무게가 무너진다.
단, 이는 **처음 마주하는 지출** 기준이다. 강화 고단계처럼 앞 단계를 전부 거쳐야
도달하는 가격은 전직을 넘어도 된다 (상세: [8-3](#8-3-장비-강화)).

장비 수치는 **+5% ~ +20%** 범위. 이걸 넘기면 "장비 없으면 손해"가 되어 스트레스가 된다.

## 8-0. 판매 — 짐이 되면 안 된다

더 좋은 장비가 나오면 쓰던 건 짐이 된다. **전직으로 잠긴 것도 마찬가지다.**
팔 수 없으면 가방이 못 쓰는 물건으로 계속 불어난다.

```
판매가 = floor(기준값 × 0.4) + floor(강화에 부은 골드 × 0.2)
기준값 = 상점가(있으면) 또는 등급값 F 50 / D 120 / C 300 / B 700 / A 1500 / S 3000
```

- 되판다고 산 값을 다 돌려주지는 않는다 (**40%**)
- 단, **강화에 부은 골드는 조금 더 돌려준다**. 안 그러면 강화한 장비를 영영 못 버린다
- **장착 중인 건 못 판다.** 먼저 벗어야 한다 — 실수로 쓰던 장비를 날리지 않게
- 되돌릴 수 없으므로 **인라인 2단계 확인** (퀘스트 삭제와 같은 패턴)
- **직업이 안 맞아 장착이 막힌 아이템도 팔 수 있다.** 못 쓰는데 못 파는 게 최악이다

## 8-1. 골드를 태우는 곳 (sink)

**고정가 상점 하나만으로는 부족하다.** 살 걸 다 사고 나면 골드가 고인다.
sink는 **바닥이 있는 것**과 **바닥이 없는 것**을 섞어야 한다.

| sink | 성격 | 가격 | 바닥 |
|---|---|---|---|
| 상점 (도구·기본 치장) | 1회성 | 100 ~ 1,500 G | 있음 — 다 사면 끝 |
| **뽑기 「나비의 상자」** | **반복** | 300 G / 10연 2,700 G | **없음** |
| 퀘스트 리롤 | 반복 | 50 G | 없음 |
| 쉬어가기 부적 (소모품) | 반복 | 800 G | 없음 |
| **장비 강화** | **장기** | 20 G ~ 20,000 G (단계·등급별) | 있음 — 단, 매우 깊다 |
| **파괴 방지 부적** (소모품) | 반복 | 500 ~ 5,000 G | 없음 |
| 전직 | 희소 | 5,000 G × (횟수+1) | 사실상 없음 |

**퀘스트 리롤**은 특히 값어치가 있다. AI가 엉뚱한 퀘스트를 뽑았을 때 지금은 지우는 수밖에 없는데,
50 G에 다시 뽑게 하면 소액 반복 sink이면서 동시에 실제 불편을 해결한다.

## 8-2. 뽑기 — 「나비의 상자」

### 원칙 세 가지

1. **꽝이 없다.** 최소 F등급 치장이 확정으로 나온다. 골드를 넣고 빈손으로 나오지 않는다
2. **치장만 나온다.** 장비·도구는 상점과 퀘스트 드랍으로만. 능력이 확률에 갇히면
   "안 뽑히면 손해"가 되어, 성실히 산 사람이 운 때문에 손해 보는 구조가 된다.
   치장만 넣으면 뽑기는 **순수한 상방**이 된다
3. **확률을 공개한다.** 숨기지 않는다

### 확률

| 등급 | 확률 | 내용 |
|---|---|---|
| F | 50% | 기본 치장 |
| D | 25% | 기본 치장 |
| C | 15% | 색 변형 |
| B | 7% | 소품 |
| A | 2.5% | 이펙트 달린 치장 |
| S | 0.5% | **뽑기 한정 치장** |

**S등급은 뽑기에서만 나온다.** 여기에만 있는 게 없으면 돌릴 이유가 없다.

### 천장과 중복

- **50회 안에 A 이상 확정** (카운터는 A 이상이 나오면 초기화)
- 중복이 나오면 **나비의 비늘**로 전환 → 비늘 100개 = 원하는 치장 1개 교환
- 즉 운이 나빠도 **결국 원하는 걸 얻는다**. 확률은 속도를 정할 뿐, 도달 여부를 정하지 않는다

### 왜 이 앱에 어울리나

골드는 **하루를 성실히 산 대가**로만 들어온다. 현금으로 살 수 없다.
그 골드를 태우는 놀이가 뽑기이고, 걸리는 건 골드뿐이며 능력은 걸려 있지 않다.
잃을 게 없으니 뽑기가 **벌이 아니라 보상**으로 작동한다.

### 뽑기 연출 — 여기가 제품의 절반이다

강화는 "성공하느냐"가 재미지만, 뽑기는 **결과가 나오기 전 3초**가 재미다.
꽝이 없으니 긴장이 아니라 **기대**를 설계해야 한다.

#### 타임라인

| 구간 | 시간 | 연출 |
|---|---|---|
| **투입** | 0 ~ 200ms | 소지금 차감. 상자가 화면 아래에서 위로 8px 튀어오름 (`steps(3)`) |
| **예고** | 200 ~ 1,000ms | 상자가 좌우로 흔들림. **흔들림 횟수가 등급 힌트다** |
| **개봉** | 1,000ms | 상자 뚜껑이 위로 열리고, 등급색 빛기둥이 위로 솟음 |
| **결과** | 1,200ms ~ | 아이템 카드가 빛기둥 안에서 팝인 |

#### 예고 — 흔들림 횟수로 등급을 암시한다

**이게 뽑기 연출의 심장이다.** 결과가 이미 정해져 있어도 흔들림이 길어지면 심장이 뛴다.

| 흔들림 | 암시 | 실제 등급 |
|---|---|---|
| 3회 | 평범 | F · D |
| 5회 | 기대 | C · B |
| **7회 + 상자가 커짐** | **뭔가 온다** | **A 이상** |

7회 흔들림이 나왔는데 A가 아닌 경우는 없다 — **거짓 예고를 하지 않는다.**
기대를 배신하면 다음부터 아무도 연출을 안 본다.

#### 개봉 — 빛 색이 등급이다

| 등급 | 빛기둥 색 | 추가 |
|---|---|---|
| F · D | `--ink-disabled` | 없음 |
| C | `--exp` (초록) | 없음 |
| B | `--int` (파랑) | 없음 |
| A | `--primary` (보라) | 화면 가장자리에 픽셀 반짝임 4개 |
| **S** | `--gold` (금색) | **화면 전체 금색 플래시 1프레임 + 빛기둥 2배 높이 + 2초 유지** |

빛기둥은 그라디언트가 아니라 **폭이 다른 사각형 3개를 겹친 계단 모양**이다.
픽셀 아트에서 빛은 부드럽게 퍼지지 않는다.

#### 10연차

- 10개를 **각 200ms로 빠르게** 순차 공개 (총 2초)
- 그중 **최고 등급 하나만** 위 풀 연출을 재생
- 나머지는 카드가 그리드에 툭툭 떨어지듯 배치 (`steps(2)`)

#### 스킵은 필수다

강화는 어쩌다 한 번이지만 **뽑기는 반복한다.** 3초짜리 연출을 50번 보면 고문이다.

- 화면 아무 곳이나 탭하면 **즉시 결과로 점프**
- `연출 건너뛰기` 설정을 두고, 한 번 켜면 계속 유지
- `prefers-reduced-motion`이면 기본으로 꺼짐

#### 중복 표시

이미 가진 치장이 나오면 카드에 겹쳐서 표시한다.

```
┌──────────────┐
│  [밀짚모자]   │
│   보유 중     │
│  → 비늘 +12   │
└──────────────┘
```

**"중복"이라는 단어를 쓰지 않는다.** 「보유 중 → 비늘 +12」로 쓴다.
같은 사실이지만 하나는 손해로, 하나는 획득으로 읽힌다.

#### 키프레임

```css
@keyframes box-shake {
  0%, 100% { transform: translateX(0); }
  25%      { transform: translateX(-3px); }
  75%      { transform: translateX(3px); }
}

@keyframes box-rise {
  from { transform: translateY(8px); opacity: 0; }
  to   { transform: translateY(0); opacity: 1; }
}

@keyframes beam-up {
  from { transform: scaleY(0); }
  to   { transform: scaleY(1); }
}
```

```css
@theme {
  --animate-box-rise: box-rise 200ms steps(3, end) both;
  --animate-box-shake: box-shake 110ms steps(2, end) infinite;
  --animate-beam-up: beam-up 160ms steps(4, end) both;
}
```

빛기둥은 `transform-origin: bottom`으로 아래에서 위로 자란다. `steps(4)`라 4칸으로 끊겨 올라간다.

#### 상자 스프라이트

`lib/sprite.ts`의 그리드 방식을 그대로 쓴다 (16×16, 닫힘/열림 2프레임).
새 렌더러가 필요 없고, 팔레트만 갈아끼우면 등급별 상자 색도 공짜다.

## 8-3. 장비 강화

sink 중에서 **곡선이 가장 가파르다.** 뽑기가 넓은 sink라면 강화는 깊은 sink다.

### 규칙

- **장비만** 강화한다. 치장은 외형이라 올릴 게 없고, 도구는 효과가 켜짐/꺼짐이라 단계가 의미 없다
- `+0` ~ `+10`
- 한 단계마다 장비 수치 **+1%p**
  예: `골드 +10%` 장비를 `+10`까지 올리면 `골드 +20%`
- 판정 결과는 **성공 / 유지 / 파괴** 셋이다
- **`+6`까지는 안전 구간** — 파괴가 없다. 초반에 겁먹고 강화를 안 하면 sink가 작동하지 않는다
- 파괴는 **`+7`부터**만 발생하고, 확률을 명시하며, **보호권으로 막을 수 있다**

### 비용 — 단계의 제곱 × 등급 가중치

단일 곡선을 쓰면 **F등급 잡템과 S등급 장비의 강화비가 같아진다.** 등급 배율을 곱한다.

```
비용(n, 등급) = 50 × n² × 등급배율
```

| 등급 | F | D | C | B | A | S |
|---|---|---|---|---|---|---|
| 배율 | ×0.4 | ×0.7 | **×1.0** | ×1.6 | ×2.6 | ×4.0 |

C를 기준(1.0)으로 잡았다.

| 단계 | F | D | C | B | A | S |
|---|---|---|---|---|---|---|
| +1 | 20 | 35 | 50 | 80 | 130 | 200 |
| +2 | 80 | 140 | 200 | 320 | 520 | 800 |
| +3 | 180 | 315 | 450 | 720 | 1,170 | 1,800 |
| +4 | 320 | 560 | 800 | 1,280 | 2,080 | 3,200 |
| +5 | 500 | 875 | 1,250 | 2,000 | 3,250 | 5,000 |
| +6 | 720 | 1,260 | 1,800 | 2,880 | 4,680 | 7,200 |
| +7 | 980 | 1,715 | 2,450 | 3,920 | 6,370 | 9,800 |
| +8 | 1,280 | 2,240 | 3,200 | 5,120 | 8,320 | 12,800 |
| +9 | 1,620 | 2,835 | 4,050 | 6,480 | 10,530 | 16,200 |
| +10 | 2,000 | 3,500 | 5,000 | 8,000 | 13,000 | **20,000** |
| **누적** | **7,700** | **13,475** | **19,250** | **30,800** | **50,050** | **77,000** |

### 판정 확률 — 성공 / 유지 / 파괴

| 단계 | 성공 | 유지 | 파괴 | 구간 |
|---|---|---|---|---|
| +1 ~ +3 | 100% | — | — | **안전** |
| +4 ~ +6 | 80% | 20% | — | **안전** |
| +7 | 50% | 45% | **5%** | 위험 |
| +8 | 50% | 42% | **8%** | 위험 |
| +9 | 25% | 63% | **12%** | 위험 |
| +10 | 25% | 60% | **15%** | 위험 |

**확률은 등급과 무관하다.** 비싸면서 확률까지 낮으면 이중 페널티가 되어 가혹해진다.
등급이 붙는 건 **가격**뿐이다.

`+6`까지가 안전 구간인 게 중요하다. 처음부터 파괴가 있으면 아무도 강화를 안 하고,
그러면 sink 자체가 작동하지 않는다. **안전하게 +6까지 올려두고,
거기서부터가 본인의 선택**이 되어야 한다.

### 강화 이득도 등급에 비례한다

비싼 만큼 더 올라야 투자가 정당화된다. 고정 수치가 아니라 **비율**로 붙인다.

```
한 단계당 상승 = 기본 수치 × 10%
→ +10이면 기본 수치의 2배
```

| 장비 | 기본 | 단계당 | +10 |
|---|---|---|---|
| C등급 「무명의 검」 | 골드 +10% | +1%p | 골드 +20% |
| S등급 「여명의 검」 | 골드 +20% | +2%p | 골드 +40% |

가중치를 따로 계산할 필요 없이 **기본 수치에 자동으로 비례**한다.

### 전직 5,000 G 규칙과의 관계

S등급 `+10` 강화는 20,000 G로 **전직보다 비싸다.** 앞서 세운 규칙과 충돌하는 것처럼 보이지만
그렇지 않다 — **직접 비교가 성립하지 않기 때문**이다.

전직 5,000 G는 **누구나 지금 당장 마주하는 가격**이다.
S등급 `+10`은 그 장비에 이미 57,000 G를 부은 사람만 마주하는 가격이다.
"5,000 내고 직업 바꿀까, 20,000 내고 강화할까"를 저울질하는 순간은 오지 않는다.

> 규칙을 이렇게 다듬는다:
> **처음 마주하는 지출의 최상단은 전직이 쥔다. 누적 투자의 최상단은 강화가 쥔다.**

또한 골드 수입은 고정이 아니다. 골드 보너스 장비를 끼고 레벨이 오르면
하루 100 G가 200~300 G가 된다. S등급 만렙은 **끝판 목표**지 필수 코스가 아니다.

### 유지 보정 — 결국은 성공한다

유지(실패)가 나올 때마다 **다음 시도 성공률 +5%p** (성공하거나 파괴되면 초기화).

`+10`을 25%로 시작해도 15번 안에 사실상 확정이다.
뽑기의 천장과 같은 원리다 — **확률은 속도를 정할 뿐, 도달 여부를 정하지 않는다.**

### 파괴 — 사라지되, 빈손은 아니다

파괴되면 장비는 소멸한다. 대신 **유물의 파편**이 남는다.

```
파편 개수 = 파괴 시점의 강화 단계 × 등급배율(반올림)
예: S등급 +9에서 파괴 → 9 × 4 = 36개
```

파편 용도:
- **파괴 방지 부적** 제작 (파편 50개)
- 같은 등급 장비의 강화 비용 **10% 할인** (파편 10개 소모)
- 뽑기의 **나비의 비늘**과 교환 (파편 5개 = 비늘 1개)

부어넣은 골드가 통째로 증발하지 않고 **다음 시도의 밑천**이 된다.
높은 단계에서 깨질수록 파편이 많아지므로, 뼈아픈 실패일수록 회수도 크다.

### 파괴 방지 부적

| 등급 | 가격 |
|---|---|
| F·D | 500 G |
| C·B | 1,500 G |
| A | 3,000 G |
| S | 5,000 G |

- 1회 소모. **파괴 판정이 나오면 유지(실패)로 바뀐다**
- 골드가 아니라 파편 50개로도 제작 가능
- sink가 하나 더 늘어난다 — 고단계 강화를 시도할수록 부적을 계속 사게 된다

### 위험 구간 경고

파괴 확률이 있는 단계(`+7` 이상)에서 강화를 누르면 **확인 패널**을 띄운다.
전직의 `⚠ 운명의 선택 ⚠`과 같은 컴포넌트를 재사용한다.

```
⚠ 위험 구간 ⚠
여명의 검 +9 → +10

성공 25%   유지 60%   파괴 15%
비용 20,000 G
파괴 방지 부적: 없음  [1개 구매 5,000 G]

[ 강화한다 ]  [ 돌아가기 ]
```

**확률을 숨기지 않는다.** 알고 누른 것과 모르고 당한 것은 완전히 다른 경험이다.

### 표시

아이템 이름 뒤에 단계를 붙인다. 랭크 배지와 나란히 둔다.

```
[A] 여명의 검 +7        골드 +17%
```

`+7` 이상은 `--primary` 색, `+10`은 깜빡임 (DESIGN.md의 S랭크 규칙 재사용).

## 8-4. 강화 연출

강화는 **결과를 기다리는 순간**이 재미의 절반이다. 즉시 숫자만 바뀌면 도박도 성취도 아니다.
3단계로 나눈다: **긴장 → 판정 → 결과**.

DESIGN.md 원칙을 그대로 따른다 — **blur 없음, `steps()` 이징, 정수 픽셀 이동.**
부드러운 이징을 쓰는 순간 픽셀이 아니게 된다.

### 타임라인

| 구간 | 시간 | 연출 |
|---|---|---|
| **긴장** | 0 ~ 700ms | 아이템 카드가 좌우 2px씩 `steps(2)`로 진동. 진동 주기가 점점 빨라짐 (140ms → 60ms) |
| | | `+7 → +8` 숫자가 두 값 사이를 교차 깜빡 |
| **판정** | 700ms | 진동 정지. 1프레임 정적 (100ms) — 이 정적이 긴장을 만든다 |
| **결과** | 800ms ~ | 성공 / 유지 / 파괴 분기 |

### 세 결과는 방향이 달라야 한다

같은 흔들림에 색만 바꾸면 셋이 구분되지 않는다. **움직임의 축과 무게**를 다르게 준다.

| | 방향 | 색 | 길이 | 남는 것 |
|---|---|---|---|---|
| **성공** | 위로 ↑ | 흰색 | 짧고 경쾌 (0.5s) | 올라간 단계 |
| **유지** | 좌우 ↔ | 붉은 테두리 | 가장 짧음 (0.3s) | 아무것도 안 변함 |
| **파괴** | 아래로 ↓ | 붉은 화면 | 길고 무거움 (1.2s) | 빈 슬롯 + 파편 |

### 성공

1. **흰 플래시** 2프레임 (`--surface` → `#FFFFFF` → 복귀, 각 60ms). 밝기 애니메이션이 아니라 **배경색 교체**다
2. **숫자 팝** — `+8`이 1.4배에서 1배로 `steps(3)` 축소하며 확정
3. **픽셀 파편** 8개가 카드 테두리에서 사방으로 12px 튐 → 3프레임 후 소멸 (`steps(3)`)
4. 카드 테두리가 `--primary`로 4프레임 유지 후 복귀
5. 토스트: `★ 강화 성공 — 여명의 검 +8 ★`

### 유지 (실패)

1. **좌우 진동** 4프레임, 성공보다 짧고 날카롭게 (각 50ms, 3px)
2. 카드 테두리가 `--danger`로 2프레임 깜빡
3. 아이템 스프라이트가 1프레임 동안 회색 팔레트(`LOCKED_PALETTE`)로 교체 → 복귀
   — 스프라이트가 데이터라 팔레트만 바꾸면 되니 공짜다
4. 소지금 숫자가 `--danger` 색으로 감소 후 원래 색 복귀
5. 토스트: `강화 실패 — 다음 성공률 30%`

**유지 연출에 파괴를 암시하는 표현을 쓰지 않는다.** 깨지는 이펙트, 조각나는 스프라이트 금지.
파괴와 헷갈리면 안 된다 — 아이템은 멀쩡하고 골드만 나갔다는 게 한눈에 보여야 한다.

### 파괴

셋 중 가장 길고 무겁다. **아래로 떨어지는 축**이 파괴의 정체성이다.

1. **큰 진동** 6프레임 (각 70ms, 4px) — 유지보다 느리고 크다. "뭔가 잘못됐다"는 신호
2. **화면 전체 붉은 플래시** 1프레임 (120ms). 카드가 아니라 화면 전체다 —
   세 결과 중 유일하게 화면 단위로 반응한다
3. 아이템 스프라이트가 **파편 12개로 흩어짐**. 성공의 파편과 달리 **중력 방향**으로 떨어진다
   (`--dy`는 전부 양수, `--dx`는 좌우로 분산, 220ms `steps(4)`)
4. 카드가 위로 2px 튀었다가 **아래로 8px 떨어지며** 소멸 (`steps(3)`)
5. 자리에 **빈 슬롯**(점선 테두리)과 **획득한 파편 개수**가 남는다
6. 토스트: `--danger` 배경으로 `✕ 파괴 — 여명의 검 +9 ✕` / 하단에 `유물의 파편 36개 획득`

**파괴 토스트만 배경색이 다르다.** 레벨업·해금·강화 성공은 전부 `--primary`,
파괴만 `--danger`. 색 하나로 "이건 다른 종류의 사건"이 전달된다.

**파괴 직후 재구매를 권하지 않는다.** "다시 도전!" 같은 버튼을 띄우지 않는다.
손실 직후의 충동을 앱이 부추기면 안 된다.

파편은 `--dx` / `--dy`를 인라인 스타일로 각각 다르게 주면 방향이 갈라진다.
- **성공**: 8개, 사방 (0°, 45° … 315°), 반지름 12px
- **파괴**: 12개, `--dy`를 전부 양수로 (아래로만), 8~20px 랜덤 — 중력 느낌

### 접근성

`prefers-reduced-motion`이 켜져 있으면 **연출 전체를 건너뛰고 결과만 표시**한다.
globals.css에 이미 전역 규칙이 있으므로 자동으로 적용되지만,
"긴장 → 판정" 구간의 **지연 800ms도 함께 0으로** 만들어야 한다.
애니메이션만 끄고 대기 시간이 남으면 그냥 느린 앱이 된다.

## 9. 안 할 것

- **꽝이 있는 뽑기** — 성실히 번 골드를 넣고 아무것도 안 나오면 그건 벌이다
- **능력이 걸린 뽑기** — 장비·도구가 뽑기에서 나오면 "안 뽑히면 손해"가 되어 스트레스가 된다
- **경고 없는 파괴** — 파괴는 넣되, `+6`까지는 안전하고, 확률을 공개하고, 부적으로 막을 수 있다
- **파편 없는 파괴** — 부어넣은 골드가 통째로 증발하면 그건 벌이다. 파편으로 일부 회수된다
- **손실 직후 재구매 유도** — 파괴 화면에 "다시 도전!" 버튼을 두지 않는다
- **내구도 / 수리** — 관리 부담만 늘고 재미가 없다
- **거래 / 교환** — 단일 사용자 앱이다
- **도구 3개 이상 동시 장착** — AI 응답이 산만해진다
- **현금 결제** — 골드는 오직 하루를 산 대가로만 얻는다
