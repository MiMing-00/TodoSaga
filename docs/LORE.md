# TodoSaga 세계관 · 용어집

> 투두 앱이므로 **뜻이 흐려지면 안 된다.**
> 세계관 이름을 앞에 두되, 현실에서 무슨 일인지는 항상 따라붙게 한다.
> `완력` 뒤에 작게 `운동` — 이 규칙을 어기면 그냥 못 알아먹는 앱이 된다.

## 등장인물

| | |
|---|---|
| **용사** | 사용자. 하루를 살아내는 사람 |
| **나비** | 안내자 **고양이**. 할 일을 듣고 **의뢰서**로 옮겨 적는다. AI가 맡는다 |

> **나비는 고양이다.** 한국에서 이름 모를 고양이를 부르는 그 이름이다.
> 나비(butterfly)가 아니므로 날개·비늘·깃털 같은 말을 쓰지 않는다 —
> 꼬리, 앞발, 수염, 털로 쓴다.

## 다섯 자질

능력치가 아니라 **자질**이다. 숫자가 아니라 살아온 흔적이라는 뜻.

| 코드 | 이름 | 현실 | 무엇을 재는가 |
|---|---|---|---|
| STR | **완력** ⚔ | 운동 | 몸을 밀어붙인 만큼 쌓인다 |
| INT | **지혜** ✦ | 공부 | 읽고 익히고 만들어낸 흔적 |
| CHA | **인망** ♥ | 사교 | 사람과 마주 앉은 시간이 남긴 것 |
| VIT | **생명력** ✚ | 건강 | 잘 자고 잘 먹은 날들의 총합 |
| LUK | **여흥** ★ | 취미 | 쓸모없어 보이지만 결국 남는 것 |

한 자질이 **100**에 이르면 그 길의 직업이 열린다.

## 다섯 갈래 길

| 자질 | 직업 | 전용 도구 |
|---|---|---|
| 완력 | **전사** | 훈련 일지 |
| 지혜 | **현자** | 집중의 회중시계 |
| 인망 | **음유시인** | 대화의 실마리 |
| 생명력 | **수도사** | 몸의 소리 |
| 여흥 | **방랑자** | 우연의 주사위 |

칭호는 레벨 구간으로 붙는다 — **견습 / 숙련 / 명예 / 전설**.

## 용어

| 화면에 쓰는 말 | 뜻 |
|---|---|
| **의뢰 / 의뢰서** | 퀘스트. "나비에게 의뢰하기"로 받는다 |
| **완수** | 완료 |
| **장(章)** | 하루. 하루가 끝나면 "오늘의 장이 닫힙니다" |
| **사가의 서** | 날짜별 기록. 나비가 받아 적어 둔 책 |
| **불씨** 🔥 | 연속 기록. 하루 하나만 완수해도 이어진다 |
| **나비의 털** | 중복으로 얻은 치장이 남기는 것. 100개로 원하는 치장과 교환 |
| **상시 의뢰** | 반복 루틴. 등록해두면 해당 요일에 원클릭으로 받아온다 |
| **이레의 표식 / 한 달의 증표 / 백일의 화관** | 연속 기록 7·30·100일 보상 |
| **호감도** | 나비가 용사를 모시는 깊이. 쓰다듬으면 오른다 (하루 5회). **상한을 보여주지 않는다** |

### 집사의 계급 (호감도)

수습 집사 → 정식 집사 → 전속 집사 → 가신 → 집사장 → 노집사 →
**둘도 없는 벗** → 평생의 집사 → 영영 함께

주종으로 시작해 **주종을 넘어서는** 순서다. "곁을 내어줌" 같은 애완동물식 표현은 쓰지 않는다.
| **그림자** | 놓친 의뢰가 남기는 것. 다음 날 EXP가 깎인다 |
| **여비** | 소지금 |
| **전리품** | 완수하고 받은 물건 |
| **봇짐** | 인벤토리 |
| **벼리기** | 재료 조합 |
| **떠돌이 상단** | 상점 |
| **첫 걸음** | 「첫걸음의 신발」이 붙여주는 처음 5분 안내 |
| **대가** | 실패 시 페널티(debuff) |

## 문장 톤

- 나비는 **정중하되 가끔 단호하다** (`QUEST_SYSTEM_PROMPT`에 정의).
  **나비는 집사다 — 어떤 짧은 말이라도 반말을 쓰지 않는다.**
  말풍선처럼 한두 글자짜리 대사도 마찬가지다 ("그만 만져" ✕ / "이만 하시지요" ○)
- 시스템 문구는 **말을 걸듯이**. "남은 퀘스트 3개" 대신 "아직 3건이 남았어요. 한 걸음씩이면 됩니다."
- **혼내지 않는다.** 놓친 날에도 "불씨는 그대로예요. 오늘 다시 채우면 됩니다."
- 빈 화면도 세계의 일부다. "나비가 앞발을 모으고 기다리고 있어요."

## 지키는 선

- **탭 이름은 평범하게** — 퀘스트 / 캐릭터 / 소지품 / 상점 / 기록.
  길을 찾는 문구까지 세계관으로 덮으면 헤맨다
- **한자어 남발 금지.** 읽고 바로 뜻이 오는 말만 쓴다
- **자질 이름 옆에는 항상 현실 분류를 작게 붙인다**
